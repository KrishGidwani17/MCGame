How do I set up sync? (one-time, free)
  1. Go to console.firebase.google.com and create a project (no Analytics needed).
  2. In the project: Build → Realtime Database → Create Database. Start in test mode.
  3. Project settings (gear) → Your apps → Web (</>), register an app, and copy the firebaseConfig values.
  4. Open index.html, find FIREBASE_CONFIG near the top of the script, and paste the values in. Commit it.
  5. Reload the site. Create a room, share the invite link, done.
